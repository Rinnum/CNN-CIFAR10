## Project Overview

This project implements a **Convolutional Neural Network (CNN)** for image classification using the **CIFAR-10 dataset**.

The objective is to develop a deep learning model that can automatically classify images into one of **10 predefined categories**. The CNN learns visual features such as edges, shapes, textures, and patterns from the training images.

The model achieved a **70.86% test accuracy** on the CIFAR-10 test dataset.

This project was completed as part of the **EncoderX Remote Internship – AI/ML Batch 02, Week 01**.

## Model Performance

The final model achieved the following results on the CIFAR-10 test dataset:

| Metric | Score |
|--------|------:|
| Test Accuracy | **70.86%** |
| Precision | **71.28%** |
| Recall | **70.86%** |
| F1-Score | **70.18%** |

These results show that the CNN successfully learned meaningful visual features from the CIFAR-10 dataset and was able to classify images across the 10 categories.

## Model Strengths

The model demonstrated several strengths:

- Achieved **70.86% test accuracy**.
- Achieved **71.28% precision**.
- Achieved **70.86% recall**.
- Achieved **70.18% F1-score**.
- Successfully learned useful visual features from CIFAR-10 images.
- Data augmentation was used to improve generalization.
- Dropout was used to help reduce overfitting.
- The model successfully classified images across the 10 CIFAR-10 categories.

## Conclusion

This project demonstrates the use of a **Convolutional Neural Network for CIFAR-10 image classification**.

The model achieved a **70.86% test accuracy**, with **71.28% precision, 70.86% recall, and 70.18% F1-score**.

These results demonstrate that the CNN successfully learned useful visual features from the CIFAR-10 dataset. The model provides reasonable classification performance, while further improvements such as a deeper CNN architecture, better data augmentation, hyperparameter tuning, and transfer learning could potentially improve its performance.
